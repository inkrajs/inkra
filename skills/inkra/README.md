# Inkra Skill

用一个入口向 AI 描述你的产品需求，由它发现合适的组件文档和设计 skill，完成接入、选型或界面实现。

## 让 AI 完成接入

把下面这段话发给你正在使用的 AI：

```text
请按照这份指南，把 Inkra 接入当前项目，并沿用现有项目结构和主题：
https://inkrajs.github.io/start.md
```

AI 会识别当前运行时与仓库结构，复用已有能力，选择适合该工具的项目级接入方式。接好后直接描述界面需求即可。入口会按需读取组件文档和设计说明；如果运行时无法持久安装，也可以读取说明完成当前任务，并明确后续是否会自动发现。

## 手动安装与直接调用

在项目目录运行（需要 Node.js 22.20 或更新版本）：

```bash
npx skills add inkrajs/inkra --skill inkra
```

使用通用 [skills CLI](https://github.com/vercel-labs/skills)，不需要 Inkra 专用安装器。CLI 会识别当前 Agent，或提示选择目标 Agent。默认仅安装到当前项目；需要跨项目使用时追加 `-g`。

备用方式：下载文档站提供的 ZIP，或复制本仓库完整的 `inkra` 目录，放入工具支持的技能目录。保留 `SKILL.md`、`references` 和其他随附文件，避免多套一层同名目录；更新前比较已有本地修改。

支持技能的运行时通常可以自动发现；如未显示，按该工具的刷新方式处理。下面是需要显式调用时的 Codex 示例，其他工具使用自己的调用语法：

```text
使用 $inkra，把 Inkra 接入这个 React 项目，添加一个可点击的按钮。
保留现有项目结构和主题。
```

```text
使用 $inkra，做一个包含依赖关系、等级和升级成本的技能树。
先找现有组件，再组织界面，升级后真实更新状态。
```

```text
使用 $inkra，看看这个管理列表适合用哪些组件。
比较选型并给出依据，先不要修改代码。
```

## 它如何组织其他 skill

- `inkra-docs`：找到组件库、当前可用组件、API、示例和接入办法。
- `inkra-design`：按业务流程组织组件、状态、布局和交互；需要时再设计自定义图标。

三个 skill 都能独立安装、使用和维护。`inkra` 从可用技能目录或官方能力目录发现它们，按当前任务读取说明；读取远程说明不代表已经安装，也不会自动替你安装其他 skill。文档能力与设计能力可以组合，已读资料会复用。

## 获取与使用边界

[公共能力目录](https://inkrajs.github.io/skills/registry.json) · [组件文档](https://inkrajs.github.io/docs/getting-started) · [AI 指令入口](SKILL.md)

文档站部署对应资料后，能力目录会提供各 skill 的独立说明与下载地址。尚未提供这些地址的旧站点，可使用项目中的 skill 目录和现有公开文档。只复制本目录也可安装总入口；联网时它按需要读取其他 skill 的公开说明，离线时需要相应本地资料并说明验证范围。

skill 不会为项目自动安装组件库。代码以项目实际安装的版本为准；应用版本、最新 npm 版本和文档展示版本会分别核对。发布、部署和升级依赖仍以你的任务授权为准。
