# Inkra Design Skill

把业务需求组织成可用的 Inkra 界面：选择组件组合、安排信息层级、连接真实状态与操作，并沿用项目主题。
需要时，也能制作与现有组件协调的自定义图标。

## 安装与调用

在项目目录运行（需要 Node.js 22.20 或更新版本）：

```bash
npx skills add inkrajs/inkra --skill inkra-design
```

使用通用 [skills CLI](https://github.com/vercel-labs/skills)，不需要 Inkra 专用安装器。CLI 会识别当前 Agent，或提示选择目标 Agent。默认仅安装到当前项目；需要跨项目使用时追加 `-g`。

备用方式：下载文档站提供的 ZIP，或复制本仓库完整的 `inkra-design` 目录，放入工具支持的技能目录。保留 `SKILL.md`、`references` 和其他随附文件，避免多套一层同名目录；更新前比较已有本地修改。

可以直接使用 `$inkra-design`，也可以只安装统一入口 `$inkra`，让它按需要发现本 skill。各 skill 独立使用，不要求同时安装。新建对话后可以这样说：

```text
使用 $inkra-design，为现有项目做一个任务面板。
包含任务列表、完成进度与领取奖励；操作要真实更新状态。
沿用当前主题，手机改为单列，不增加无关功能。
```

## 常用请求

### 从需求组织组件

```text
使用 $inkra-design，设计一个技能升级界面。
需要看依赖、等级、升级成本和技能详情。
先确认可用组件，再说明数据、未解锁、资源不足、可升级和满级状态如何衔接。
```

### 调整已有页面

```text
使用 $inkra-design，调整这个页面的层级、间距和操作区。
保留现有文案、业务逻辑和主题，直接修改相关代码。
```

### 只做方案或检查

```text
使用 $inkra-design，为一个装备比较界面给出布局和交互方案。
说明桌面与手机如何组织，暂时不写代码。
```

```text
使用 $inkra-design，检查这个界面，优先列出影响使用的几处问题。
重点看信息层级、状态反馈、键盘操作和小屏布局，先不要修改代码。
```

### 需要自定义图标

```text
使用 $inkra-design，制作炼金药瓶图标的线框与填充外观。
孔洞透明，配色跟随主题，使用 PencilIcon 的公开 API，检查实际小尺寸效果。
```

## 提供哪些信息

页面用途与主要操作、已有组件或相关代码、实际安装版本、当前主题与参考图、目标设备，以及你想要设计建议还是直接实现。不必一次写齐，可以先从一个页面开始。

skill 会先关注现有组件能完成什么，再处理组合与外观。需要确认组件/API时，它会发现并读取独立的 `inkra-docs` 说明；未安装时可读取公开资料，不会冒充已安装或自动安装其他 skill。离线或资料不足时会说明不能确认的能力。
