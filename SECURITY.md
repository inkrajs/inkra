# Security

Inkra is preparing its first release. No stable support window or response-time
guarantee is advertised yet.

Do not put credentials, private data or exploitable security reports in public
issues. During private repository preparation, use the existing private
maintainer collaboration channel. Before the repository becomes public,
maintainers must enable and verify GitHub private vulnerability reporting and
update this document with the working reporting route.

Include the affected version, minimal reproduction, impact and known mitigation.
Remove credentials and personal information. Ordinary non-sensitive visual,
documentation or accessibility issues belong in the normal issue tracker.

Candidate workflows use read-only repository permissions and do not publish.
Publication needs separate approval and reviewed authentication. Credentials
are never committed.

## 安全问题

请勿在公开 Issue 中附带凭证、私人数据或可直接利用的安全漏洞。私有筹备阶段使用已有私密维护渠道；公开前必须先启用、验证 GitHub 私密漏洞报告入口，再更新本文件。不承诺尚未建立的响应时限或版本维护周期。
